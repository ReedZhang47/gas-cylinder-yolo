# 匿名评审操作说明

当前 CLIP 自动评价已完成。这里仅提供真实人工评价入口，不展示自动分数或配置排名。

1. 两名评分者分别使用 `R1/index.html` 和 `R2/index.html`，用 Chrome 或 Edge 打开；每人独立评价全部 153 张。只有一名实际评分者时使用 R1，并告知作者按单人评价报告。
2. 每图先回答两道通过题：气瓶是否存在且正常、场景是否真实无重大缺陷；再选择三档工地照片真实性。选“不通过”或“不确定”后勾选该题的原因；只有选择“其它”才需要输入文字。确认后第一阶段锁定。
3. 第二阶段每张图片均为四道提示词相关的是非题，只选“是”或“否”。不评价气瓶具体数量，不填写实际数量，选“否”也无需说明理由。点击图片可放大查看完整画面。
4. 每次结束点击“下载评分 JSON”。下载提示会显示已完成数和待完成数；全部完成应为 **153/153**。请每次保存备份；浏览器自动保存仅用于方便恢复。换电脑或浏览器时用“导入备份”恢复。
5. 完成后把各自的 JSON 交给作者。两人不要提前交流判断，不看 CLIP 分数、配置映射或带配置的网格图。分歧将在导入后单独交由人工裁决。

仅将 R1 或 R2 整个文件夹（或各自 ZIP 解压后的文件夹）交给对应评分者。`restricted/`、上层自动报告和论文图件均不属于评审包。

当前版本为 **v3**。请使用新版页面或重新下载 ZIP。由于第二阶段题目和规则已改变，旧版评分 JSON 不自动转换；旧备份请保留，新版请重新评分。新旧浏览器保存空间相互独立。

注意：作者可能已经见过部分图片，本评价只隐去配置标签，不声称评分者从未见过数据。合理遮挡和画面边缘截断不自动否决训练可用性。第一阶段仍可选择“不确定”；第二阶段统一二选一。
